5. Changes/deviations:
Since the planning document there have been a ton of changes, mostly just narrowing down on the specifics.
We now know the three main types of puzzles we will have, exactly what each part needs to function and a general idea of how it all fits together.

We have much more refined expectations for the project, including a full breakdown of all mechanics that need to be implemented, the intended visual style of the game, and a breakdown of the tasks that need to be completed.

We have a rough timeline now requiring a very time intensive crunch through winter break and hopefully having a fully polished single player experience.
The biggest thing that has changed is definitely the scope. We have drastically reduced the scope of the project from when we were discussing it.
Our current plan is to create a three tiered tower (MVP) utilizing all of the base puzzle mechanics so we can scale it way up if we have time and make a truly impressive final project.
If not, our plan is to make the most polished MVP possible.
