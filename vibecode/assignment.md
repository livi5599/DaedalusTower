“Create me a simple character moving script that only moves with wasd no jumping or anything else fancy. Make it physics based and make sure it doesn't clip on anything like walls or floors”
“Can you make a script of multiple scripts that moves a tower separated into 3 separate parts, being able to rotate each level when selected. So if multiple are selected then multiple floors should rotate 90 degrees”

3.
Map design: It gave interesting ideas and helped tie together the entire tower and how all of the mechanics can work together.  It wasn’t good at giving visuals or explicit instructions, but it was able to describe what it was talking about.  The code it provided was basic, so it wouldn’t work for the exact needs of the tower, but it was a good start to work off of.
Puzzle design: AI was very good at coming up with ideas that are feasible to do in the given environment, but the actual implementation was a bit too complicated for it to work properly.
Character movement: It could help with basic movement, but with anything specified for the project, it required a long chain of error message debugging back and forth with ChatGPT.  Even after all of that, there were still problems.
Rotation mechanics: The AI couldn’t create a script that was even editable.  It had trouble when creating multiple scripts to implement a function that interacts with the other functions, but it was capable of helping us with individual scripts per object, or with making a singular function.
All other low level tasks that require only a script/ideas: Unable to locate specific prompts, but AI was overall pretty helpful at completing these.  For times it wasn’t as helpful, it took a short-lived back and forth to get it where it should be.
Building assets: Did not give ChatGPT any prompts for this task, but just looked at the AI tools that exist.  Regarding those tools, there were some that could turn a flat image into a gaming model.  However, they were prone to error, as there were inconsistencies in depth and level of detail, and what it produced would be too dense to make meshes that are useful in a 3D environment.

4. Based on the vibe coding, we don’t believe there are any changes to be made for our game.  We already expected AI to not be the most helpful, especially when given tasks that require a good understanding of the goal and generally complex code.  However, as proved by this assignment, AI is helpful with coming up with ideas, giving basic outlines of code/giving a direction to go with code in order to implement a feature, and debugging.
